# Tech Stack

- TypeScript ~5.8, strict/no-emit, ES2022 target, ES modules, bundler resolution.
- React 19 with React DOM 19 and React Router 7.
- Vite 7 with `@vitejs/plugin-react` and Tailwind CSS 4 Vite plugin.
- Markdown rendering: `react-markdown`, `remark-gfm`, `rehype-highlight`, Tailwind typography.
- Vitest 4 for tests.
- ESLint 9 flat config with TypeScript, React Hooks, and React Refresh rules.
- Package manager: npm; project scripts are authoritative in `package.json`.
